# Normas de convivencia

Este es un proyecto sobre deuda soberana, sanciones, arbitraje y colapso
económico: temas donde casi todo el mundo tiene una posición política. El
proyecto no pide neutralidad de opinión, pero sí exige un método común.

## Lo que se espera

- **Discutir el criterio, no la persona.** «La tasa del 6,5 % en este laudo no es
  la que fija el tribunal» es una crítica útil. «Este informe está sesgado» sin
  señalar dónde, no lo es.
- **Traer la fuente.** Cualquiera puede equivocarse; lo que no se admite es
  sostener una cifra sin documento que la respalde.
- **Aceptar la corrección.** Si el dato que trajiste no se sostiene, el camino es
  anotarlo y seguir: el dataset no es de nadie.
- **Escribir para que se entienda.** Un aporte que solo lo comprende quien lo
  escribió no sirve a un observatorio.

## Lo que no se admite

- Ataques personales, descalificaciones por nacionalidad u origen, o cualquier
  forma de acoso.
- Publicar datos personales de terceros (funcionarios, litigantes, periodistas).
  El proyecto documenta instituciones y actos, no vidas privadas.
- Presentar una cifra estimada como oficial, o una propuesta como hecho: es el
  único «pecado técnico» que este proyecto persigue de verdad.
- Usar los canales del proyecto para propaganda política de cualquier signo.

## Cómo se aplica

Los mantenedores pueden editar, cerrar o rechazar aportes que incumplan estas
normas, y pedir que se reformule. Ante un caso de acoso, se aparta a quien lo
comete y se documenta la decisión en el canal que corresponda.

## Alcance

Estas normas aplican a los canales del proyecto: *issues*, *pull requests*,
discusiones y cualquier espacio donde alguien represente al observatorio.

## Base

Estas normas son una adaptación, en lenguaje llano y orientada a un proyecto de
datos, del [Contributor Covenant v2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/),
que sigue siendo la referencia para casos no previstos aquí.
